## Authorization code with PKCE

Public clients must generate a verifier and S256 challenge.

```ts
import { createPkcePair } from "@anan/auth-sdk/client";

const pkce = await createPkcePair();
```

Send the user to authorization:

```txt
/oauth/authorize
  ?response_type=code
  &client_id=<client-id>
  &redirect_uri=<registered-callback>
  &scope=offline_access clients:read_own
  &code_challenge=<challenge>
  &code_challenge_method=S256
```

## Token exchange

Exchange the authorization code on a trusted backend when possible. Public browser clients should use the SDK’s protected flow and never store access tokens in browser storage.
