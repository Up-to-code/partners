Welcome to the Anan Partner Portal. These docs cover the production path for registering an app, installing <SDKName />, and verifying OAuth flows against an authorized Anan workspace.

<Callout title="Security model">
Partner apps should request the smallest useful scope set, use PKCE for public clients, and keep refresh/session handling on the server.
</Callout>

## What you can build

- Workspace automations that read organization clients, properties, projects, and offers.
- Internal developer tools that act on behalf of a verified organization.
- Server-side API integrations that keep secrets outside the browser.

## Portal flow

1. Create a partner programmer account.
2. Register an app with redirect URIs and scopes.
3. Verify OAuth against an authorized workspace.
4. Submit the app for Anan review.
